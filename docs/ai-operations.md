# AI運用フローと安全ゲート

## AIエージェントの役割
1. Research：公開情報から顧客課題・競合・価格仮説を調べ、出典を記録
2. Product：商品仕様、納品テンプレート、FAQを作成
3. Copywriter：顧客ごとの提案文と投稿サンプルを作成
4. QA：事実誤認、誇大表現、著作権・個人情報リスク、仕様逸脱を確認
5. Analyst：KPIを集計し、次の実験を提案
6. Orchestrator：各工程の状態を管理し、失敗時は停止してログを残す

## 自動化できること
- 公開情報の要約
- 投稿案・台本・提案文の下書き
- 形式チェック、重複チェック、KPI集計
- 承認済みテンプレートに沿ったレポート作成

## 人の承認が必要なこと
- 顧客への初回送信・契約条件の確定
- 決済、返金、アカウント作成、法的表示
- 健康・医療に関する断定表現
- 顧客データの外部AIへの入力
- 公開ページへの本番反映

## 絶対ルール
- APIキー、パスワード、顧客の秘密情報をGitHubに置かない
- AIが作った数字や実績を事実として掲載しない
- 失敗・異常時は自動で大量送信せず、停止して人へ通知
- 売上や成果を保証しない
- 顧客の許可なくSNSアカウントへログインしない

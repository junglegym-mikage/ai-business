# AI Content Studio — First Paid Offer Launch Pack

このパックは、最初の有料顧客を獲得するための最小構成です。

## 提供商品
- 対象：パーソナルジム・整体院・美容サロンなどの小規模事業者
- お試し商品：SNS投稿14日分パック 9,800円（税込想定）
- 継続商品：月間SNS運用素材パック 19,800円/月（税込想定）
- 初回納品：投稿企画、投稿文、短尺動画台本、CTA案、投稿カレンダー
- 初期は広告を使わず、サンプルと個別提案で需要を検証

価格は仮説であり、販売実績で検証すること。購入・契約・決済を受け付ける前に、特定商取引法等の表示、利用規約、プライバシー、返金条件、決済・問い合わせ導線を整えること。

## ファイル
- `index.html`: 販売ページの試作。公開前に問い合わせ先・契約条件を設定する
- `docs/offer.md`: 商品・価格・納品仕様
- `docs/30-day-plan.md`: 30日間の実行計画
- `docs/outreach.md`: 個別提案文とフォロー文
- `docs/ai-operations.md`: AI運用フローと承認ゲート
- `kpi.csv`: 毎週確認するKPI

## 最初の目標
30日以内に有料顧客1社を獲得すること。達成できない場合は、機能開発を増やす前に、対象顧客・商品・価格・提案文を修正する。

## 公開前に必須の設定
1. 問い合わせURLまたはメールアドレス
2. 決済方法
3. 契約・利用規約・返金条件
4. 特定商取引法に基づく表記等、該当する法的表示
5. 実際に提供できる範囲と納期
6. 顧客データの取り扱い方針

このパックは作業開始用のドラフトであり、公開・販売・決済設定はまだ行っていません。

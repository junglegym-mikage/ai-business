# 商品設計：SNS投稿14日分パック

## 誰向けか
パーソナルジム、整体院、美容サロンなど、SNS発信が必要だが、投稿企画・文章・動画台本を毎週作る時間がない小規模事業者。

## 顧客が買う結果
「AIを使えること」ではなく、投稿を考える時間を減らし、投稿を継続しやすくすること。

## 初回商品（需要検証用）
- 仮価格：9,800円（税込想定）
- 納品：14日分の投稿カレンダー、投稿文14本、短尺動画台本4本、CTA案、ハッシュタグ案
- 納期：必要情報受領後3営業日以内（実際に守れる体制を確認してから確定）
- 修正：事実誤認・誤字の修正1回。方向性変更は別途
- 初回限定：先着3事業者で需要と作業時間を計測。限定数は実際に対応できる数に合わせる

## 継続商品（初回購入後に提案）
- 仮価格：19,800円/月
- 月間投稿カレンダー、投稿文、短尺動画台本8本、月次振り返りテンプレート
- 自動投稿や成果保証は初期商品に含めない

## 価格の検証
価格を決め打ちせず、見込み客に提案した数、返信数、商談数、購入数、納品時間、継続意向を記録する。初期3件の実績が出るまでは機能追加に投資しない。

## 提供上の制約
- 投稿内容の正確性・業界固有情報・医療健康に関する表現は確認が必要
- フォロワー数、予約数、売上の増加は保証しない
- 顧客のパスワードを預からない。SNSアカウントへのログイン・投稿代行は初期商品に含めない
- 顧客情報をAIサービスに入力する場合は、事前に利用目的とデータの扱いを明確にする

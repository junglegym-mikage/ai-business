# ① AI実務サポート（経営者・個人事業主向け）

## 商品ページ文面
**タイトル**：面倒な事務作業を、AIで効率化。あなたの業務に合わせた「AI化セット」をお届けします

**こんな方へ**
- 問い合わせへの返信、見積書、請求の連絡、月末の集計に毎週何時間も取られている
- AIが便利なのは知っているが、自分の仕事のどこに使えばいいか分からない
- 新しいソフトを契約せずに、今あるツール（メール、表計算、無料のAI）で効率化したい

**お届けするもの**（PDF・申込内容の受領から7営業日以内）
1. 業務の棚卸し表：申込内容から、繰り返し発生している作業と1か月の時間を整理
2. AI化の優先順位：時間の削減が大きく、始めやすい順に3つ
3. AI化テンプレート：優先3業務それぞれに、そのまま使える指示文（プロンプト）と使い方の手順
4. 導入の手順書：1週目〜4週目に何をするか
5. 注意点：顧客情報をAIに入れないための工夫、AIの出力を確認するポイント

**価格**：モニター価格9,800円（税込・先着3名）。通常価格は `sales-strategy.md` の条件を満たしてから設定する（販売実績のない価格を比較表示しない）

**月次更新プラン（任意・初回をご購入の方のみ）**：月4,980円（税込）。月1回、実績をもとに現在地ボードの目標・計画を更新し、1ページの月次レポートをお届けします。1か月単位・いつでも解約可。範囲は `subscription.md` 3章

**現在地ボード**：初回に、実績を入れると目標と現在地がグラフで見えるスプレッドシートをお渡しします（ご自身のGoogleアカウントで使います）

**含まれないもの**：税務申告・労務手続き・契約書の作成や個別の判断（税理士・社労士・弁護士の業務です）、ツールの設定代行、アカウントへのログイン、継続サポート

**修正**：納品後7日以内に、事実の誤り・誤字の修正1回

（`common.md` 1章の免責を続けて掲載）

## 申込項目
1. 業種と事業の規模（例：整体院・スタッフ2名）
2. 1週間でよくやっている事務作業を、思いつくだけ（例：予約の返信、見積書、請求書、SNS投稿、売上集計）
3. そのうち特に面倒・時間がかかるもの上位3つと、1回あたりのおおよその時間
4. 今使っているツール（メール、LINE公式、Excel/スプレッドシート、会計ソフト、AIなど）
5. AIの利用経験（使ったことがない／少しある／日常的に使う）
6. 有料ツールの追加契約をしてもよいか（しない／月◯円までならよい）
7. 変えたくないやり方があれば
※ 顧客・従業員・取引先の個人情報は入力しないでください

## 架空サンプル（説明用の架空の例）
**申込内容（架空）**：整体院、スタッフ2名。面倒な作業＝①LINEでの予約の問い合わせ返信（1日10件×3分）、②回数券の残り回数の管理（週1時間）、③月末の売上集計（月3時間）。ツール＝LINE公式、スプレッドシート、無料のAI。追加契約はしない。

**納品物の抜粋**
- 棚卸し：予約返信 約15時間/月、回数券管理 約4時間/月、売上集計 3時間/月 → 合計約22時間/月（申込内容の自己申告から計算した概算。実測ではない）
- 優先1：予約返信のひな形化。よくある質問10種類の返信文をAIで作り、LINE公式の定型文に登録。見込み：月15時間 → 約5時間（仮定による試算。実際の削減時間は使い方で変わり、保証しない）
  - 指示文の例：「あなたは整体院の受付です。次の問い合わせに、丁寧で短い返信を書いてください。空き枠は【空き枠】です。料金は【料金】です。問い合わせ：【問い合わせ文。名前は入れない】」
  - 確認ポイント：空き枠・料金が正しいか、症状の改善を約束していないか
- 優先2：売上集計をスプレッドシートの関数で自動化（AIに関数を書かせる）。見込み：月3時間 → 30分（仮定による試算）
- 優先3：回数券の管理表を作り、残り回数を自動で計算
- 注意：患者さんの氏名・症状はAIに入力しない。健康に関する表現は断定しない

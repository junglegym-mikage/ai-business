## 商品ページ文面
**タイトル**：家計の今と将来を見える化｜AI家計整理・積立シミュレーション

**こんな方へ**
- 毎月なんとなくお金が残らない。どこを見直せばいいか分からない
- 物価が上がって、このままの家計で大丈夫か不安
- NISAやiDeCoが気になるが、積み立てるとどうなるのかイメージがわかない

**お届けするもの**（PDF・申込内容の受領から5営業日以内）
1. 家計の見える化：収入と支出を項目別に整理し、平均的な目安と比べたグラフ
2. 見直し候補：固定費（通信費・保険料・サブスク・住居費など）から、見直しで効果が出やすい順に3つ
3. 貯蓄計画：生活防衛資金（急な出費に備えるお金）の目安と、毎月の貯め方
4. 将来シミュレーション：毎月の積立額を「仮定の利回り」ごとに比べた試算（減る場合も含む）
5. NISA・iDeCoの制度のしくみ（一般的な説明）

**価格**：1,980円（税込）／先着3名

**このサービスの範囲**：家計の整理、一般的な制度の説明、仮定条件にもとづく試算に限ります。お一人おひとりの資産状況に応じた銘柄の選定・投資の配分・売買の判断についての助言は行いません。

**含まれないもの**：特定の銘柄・投資信託・保険・金融機関のおすすめ、投資の配分（何に何割など）の提案、売買のタイミングの助言、保険や金融商品の販売・紹介、税金の個別の計算や申告

**修正**：納品後7日以内に、事実の誤り・誤字の修正1回

**ご注意**：将来シミュレーションは、仮定の条件にもとづく計算で、将来の予測や運用成果の保証ではありません。投資には元本割れのリスクがあります。商品選びはご自身の判断で行ってください。

## 架空サンプル（説明用の架空の例）
**申込内容（架空）**：夫婦＋子ども1人、30代。手取り30〜40万円。通信費2台で月1.8万円、保険料月3.2万円、サブスク5件。試したい積立額：月3万円。

**見直し候補の抜粋**
- 通信費：格安プランの一般的な料金帯と比べ、月の差額の目安を示す
- 保険：保障の重複がないか確認する観点（どの保険がよいかはすすめない）
- サブスク：利用頻度で解約候補を整理

**将来シミュレーション（仮定条件にもとづく試算。予測・保証ではありません）**
前提：毎月3万円を20年間積立（元本720万円）、運用手数料 年0.1%、物価上昇 年2%、税金は考慮前

| 想定利回り（年） | 20年後の額（名目） | 物価上昇を考えた実質額 |
|---|---|---|
| −2% | 約588万円（元本割れ） | 約396万円 |
| 0% | 約713万円（手数料分だけ元本を下回る） | 約480万円 |
| 3% | 約974万円 | 約656万円 |
| 5% | 約1,219万円 | 約820万円 |

- 下落の例：年5%で19年間積み立てた後、最後の1年の初めに30%下落し、その後横ばいだった場合は約824万円。
- 税金の例：年5%のケースを課税口座で全額売却した場合、利益（約499万円）に20.315%がかかり約101万円。NISAの非課税枠内であれば利益は非課税（ただしNISAで出た損失は他の口座の利益と相殺できません）。
- 計算方法：毎月末に積立、月複利。再現用のコードは仕様書の付録と同じ方法。

# ③ AI目標達成ロードマップ（一般の方向け）

## 商品ページ文面
**タイトル**：ゴールまでの「ルート」と「今いる場所」が一枚でわかる。AI目標達成ロードマップ

**こんな方へ**
- 資格・副業・転職・ダイエット・貯金など、やりたいことはあるのに何から始めればいいか分からない
- 計画を立てても途中で崩れて、どこまで進んだのか分からなくなる
- 遠回りしていないか、自分の進め方を一度整理したい

**お届けするもの**（PDF・申込内容の受領から5営業日以内）
1. ゴールの具体化：期限と「達成した」と言える基準
2. ルートマップ：ゴールまでの道筋を3〜5つの段階（マイルストーン）に分け、今どの段階にいるかを図で表示
3. 別ルートの比較：時間・お金・難しさの違う進め方を2〜3通り
4. 最初の4週間の週次計画
5. 週次チェック表：毎週記録して、遅れたら計画を直すための表と直し方のルール

**価格**：2,980円（税込）／先着3名

**含まれないもの**：継続的なコーチング、医療・健康に関する個別の指導、収入の保証

**修正**：納品後7日以内に、事実の誤り・誤字の修正1回

## 申込項目
1. 達成したい目標（自由記述）
2. いつまでに達成したいか
3. 今の状況（例：勉強はまだ始めていない、体重◯kg、副業の月収0円）
4. 使える時間（平日・休日それぞれ1日何時間）
5. 使える予算（目安）
6. これまで試したこと、つまずいたこと
7. 苦手なこと・避けたいこと（例：朝が弱い）
※ 健康に関する目標の場合、持病や治療中の病気がある方は先に医師にご相談ください

## 納品テンプレート
```
1. ゴールの具体化（期限／達成の基準）
2. ルートマップ（図）
   スタート ── M1 ── M2 ── M3 ── ゴール
               ▲ 現在地
   各マイルストーン：内容／目安の時期／達成の確認方法
3. 別ルートの比較（表：ルート／期間／費用／難しさ／向いている人）
4. 最初の4週間の週次計画（週ごとのやること・時間）
5. 週次チェック表（予定／実績／差／次週の調整）と計画の直し方
   - 2週続けて7割未満なら、量を減らすか期限を延ばす
   - 3週続けて達成したら、次の段階へ進む
6. 免責
```

## 架空サンプル（説明用の架空の例）
**申込内容（架空）**：目標＝来年6月の簿記2級合格。今＝簿記3級合格済み、2級は未着手。平日1時間・休日3時間。予算1万円。過去に独学で途中で止まった。

**ルートマップの抜粋**
```
スタート ── M1 商業簿記の基礎 ── M2 工業簿記 ── M3 過去問演習 ── ゴール（6月受験）
   ▲ 現在地（11月）    〜1月             〜3月          〜5月
```
- 別ルート：A 独学（テキスト＋問題集 約5,000円）／B 通信講座（数万円・質問できる）／C 先に工業簿記から（得点源を先に固める）
- 最初の4週間：1週目 テキスト第1〜2章。使える時間は週11時間（平日1時間×5日＋休日3時間×2日）だが、計画は8割の約9時間で組む…
- 直し方：過去に途中で止まったため、週の計画は使える時間の8割で組む

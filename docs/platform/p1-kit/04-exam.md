# ④ AI受験ロードマップ（中学・高校・大学受験／保護者向け）

## 商品ページ文面
**タイトル**：志望校までの「現在地」と「これからの勉強方針」を見える化。AI受験ロードマップ

**こんな方へ**
- 模試の結果を見ても、何をどれだけ勉強すればいいか分からない
- 受験までの残り時間で、今のやり方で間に合うのか不安
- 塾や家庭学習の方針を、親子で話し合う材料がほしい

**対象**：中学受験・高校受験・大学受験（受験の種類ごとに専用のテンプレートで作成します）

**お届けするもの**（PDF・申込内容の受領から5営業日以内）
1. 現在地の整理：模試・テストの結果から、教科ごとの強み・弱みと志望校との差
2. 受験日からの逆算スケジュール：時期ごとの目標（基礎固め→応用→過去問）
3. 教科別の勉強方針と1週間の時間配分
4. 次の模試までのチェックポイント
5. 模試後の見直し1回（下の「見直しの条件」参照）

**価格**：モニター価格3,980円（税込・模試後の見直し1回を含む・先着3名）。通常価格は `sales-strategy.md` の条件を満たしてから設定する

**現在地ボード**：初回に、模試の結果を入れると教科別の現在地と志望との差が見えるスプレッドシートをお渡しします（月次更新プランは現在準備中）

**含まれないもの**：授業・個別指導・添削・質問対応などの学習指導、合格の保証、入試制度の個別の確認（最新の募集要項は学校の公式情報でご確認ください）

**修正**：納品後7日以内に、事実の誤り・誤字の修正1回（下の「模試後の見直し」とは別の対応です）

**見直しの条件**
| 項目 | 内容 |
|---|---|
| 対象 | 初回納品日から3か月以内に受けた模試・テストの結果1回分 |
| 提出期限 | 初回納品日から3か月以内 |
| 提出方法 | ココナラのトークルームに、教科ごとの偏差値（または点数）を書いて送る（本名・学校名・模試の受験番号は送らない。外部フォームは使わない） |
| 再納品 | 提出の受領から5営業日以内 |
| 更新する内容 | 現在地（教科別の差）、教科の優先順位、1週間の時間配分、次の模試までの計画とチェックポイント |
| 含まれないもの | 志望校・受験方式の変更に伴う作り直し、2回目以降の見直し、継続的な質問対応、授業・添削 |
| 期限を過ぎた場合 | 見直しは終了します（返金の対象にはなりません） |

**お申し込みは保護者の方からお願いします。**
（`common.md` 1章の免責を続けて掲載）

## 申込項目（保護者が入力。本名・学校名は不要）
1. 受験の種類（中学／高校／大学）と受験予定の年月
2. 学年
3. 志望校のレベル（例：偏差値の目安、第1〜第3志望の目安。学校名は任意）
4. 最近の模試・テストの結果（教科ごとの偏差値または点数の目安、2回分あると精度が上がります）
5. 1週間に勉強できる時間（平日・休日）と、塾・通信教材の利用状況
6. 得意・苦手な教科、本人の様子で気になること
7. 大学受験のみ：受験方式（共通テスト利用・一般・総合型など）と必要な教科
※ 本名・学校名・住所は入力しないでください

## 納品テンプレート（受験の種類で切り替え）
```
共通
1. 現在地（教科別の表：今の偏差値・点数の目安／志望校の目安／差）

大学受験版：受験方式ごとの必要教科、共通テストと個別試験の配分、過去問に入る時期
```

## 架空サンプル（説明用の架空の例・高校受験版）
**申込内容（架空）**：中学2年、受験は再来年3月。志望は偏差値60前後の公立高校。直近2回の模試：英語58・数学49・国語56・理科52・社会55。平日1.5時間・休日4時間。塾なし。

**抜粋**
| 教科 | 今 | 志望の目安 | 差 | 方針 |
|---|---|---|---|---|
| 数学 | 49 | 60 | −11 | 最優先。中1・中2の計算と関数の基礎を3か月で固める |
| 理科 | 52 | 60 | −8 | 計算問題（電流・化学）を重点に |
| 英語 | 58 | 60 | −2 | 単語と長文を毎日少しずつ。維持しながら伸ばす |

- 逆算：中2の冬まで＝基礎固め（数学に週の4割）→ 中3の夏まで＝全範囲の基礎 → 中3の秋から＝過去問
- 次の模試のチェックポイント：数学の計算・関数の基本問題の正答率8割
- 注意：内申点の扱いと入試日程は、志望地域の教育委員会の公式情報で確認してください

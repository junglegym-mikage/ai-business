# 共通ルール（全サービス）

## 1. 全商品ページに入れる免責（共通部分）
- 本サービスは、AIを使って作成した計画・資料を、運営者が確認したうえでお届けするものです。
- 売上・収入・資産の増加、目標の達成、合格などの結果を保証するものではありません。
- 本サービスは、税理士・社会保険労務士・弁護士・ファイナンシャルプランナー等の専門家による個別の助言ではありません。専門的な判断が必要な場合は、各専門家にご相談ください。
- 掲載している事例はすべて説明用の架空の例です。

## 2. 申込フォームの冒頭に置く同意文（チェック必須）
□ 入力内容は、計画・資料の作成のため、氏名・連絡先を除いたうえでAIサービスで処理されることに同意します（AIサービスの学習には使われない設定で利用します）。
□ 入力内容と作成用の作業データは、納品後【②④：30日／①③：90日】で削除されることを理解しました。それ以前の削除も【問い合わせ先】に連絡すれば7日以内に対応されます（決済・返金などの取引記録は、法令で保存が必要な期間は別に保管されます）。
□ 結果を保証するものではないこと、専門家による個別の助言ではないことを理解しました。
□ （④のみ）私は受験生の保護者であり、この申込に同意します。

## 3. 入力してもらわない情報（全サービス共通）
- 口座番号、カード番号、各種ID・パスワード、マイナンバー
- 顧客・従業員・取引先など第三者の個人情報（①）
- 受験生の本名・学校名（④）

## 4. 納品・修正・返金
| 項目 | 内容 |
|---|---|
| 納期 | 申込内容の受領から各商品ページの営業日数以内 |
| 修正 | 納品後7日以内に、事実の誤り・誤字の修正を1回。方向性の変更・追加相談は対象外 |
| 返金 | 【オーナーが決定。例：納期を守れなかった場合は全額】。販売プラットフォームの規定にも従う |
| 問い合わせ | 【問い合わせ先】。返信は【営業日】以内 |

## 5. 禁止表現チェック（納品物・投稿・商品ページすべて）
納品・公開の前に次が含まれていないか確認する。
- 保証・断定：「必ず」「確実に」「絶対」「100%」「合格保証」「元本保証」「誰でも稼げる」
- 個別の投資推奨：特定の銘柄・投資信託・金融機関・保険商品をすすめる表現
- 実在しない利用者の声・実績の数値
- 医療・健康の断定（③で健康目標を扱う場合）
- 法律・税務・労務の個別判断（①）

## 6. 記録（個人情報なし）
`ledger-template.csv` に、受付番号（例：B-001）、商品、日付、作業時間の内訳、満足度、返金の有無、削除日だけを書く。氏名・連絡先・申込内容は書かない。

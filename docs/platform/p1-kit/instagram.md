## 投稿案（各3本。すべてリールで出す：図解が動く形か、スライドを順に見せる形）
すべての投稿の最後の2秒：「事例は架空です／結果を保証するものではありません／詳しくはプロフィールのリンクから」

### 月・土：経営・仕事（①・売上の主軸）
1. **「事務作業の時間、数えたことありますか？」** 1枚目タイトル → 業務の棚卸し表の書き方 → 架空の整体院で月22時間 → 「まず数える」がAI化の第一歩
2. **「AIにそのまま渡せる予約返信のひな形」** 指示文の例（名前・個人情報は入れない）→ 確認ポイント3つ
3. **「AIに入れてはいけない情報」** 顧客の氏名・連絡先、パスワード、契約書の原本 → 置き換え方（【顧客名】のように伏せる）

### 火：家計・お金（②）
1. **「固定費を見直す順番」** 通信 → サブスク → 保険の確認観点 → 住居（どの商品がよいかはすすめない）
2. **「毎月3万円を20年積み立てたら？（仮定の試算）」** 利回り−2%／0%／3%／5%の4パターン表 → 元本割れもありうる → 物価上昇を考えると実質額は小さくなる → 予測・保証ではない
3. **「NISAで知っておきたい3つのこと」** 非課税になるのは利益 → 課税口座なら利益に原則20.315% → NISAの損失は他の口座の利益と相殺できない → 最新情報は金融庁の公式情報で

### 水：目標達成（③）
1. **「目標が続かないのは、現在地が見えないから」** ルート図（スタート→M1→M2→M3→ゴール、▲現在地）
2. **「計画は使える時間の8割で組む」** 理由と、遅れたときの直し方ルール（2週続けて7割未満なら量を減らす）
3. **「同じゴールでもルートは1つじゃない」** 架空の簿記2級：独学／通信講座／工業簿記から の比較表

### 木：受験・学習（④）
1. **「模試の結果、どう読む？」** 教科別の「今」と「志望の目安」の差を表にする → 差が大きい教科から優先
2. **「受験日から逆算する4つの時期」** 基礎 → 全範囲 → 応用 → 過去問（中学・高校・大学で時期が違う）
3. **「親子で話すための1枚」** 1週間の時間配分表のつくり方（塾・部活との両立）→ 合格を保証するものではない、入試情報は公式で確認

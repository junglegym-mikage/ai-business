# プライバシーポリシー（草案）

> 草案です。`【 】` はオーナーが入力・確認する箇所。公開前に、使用するAIサービスの最新の規約・データの扱いを確認し、必要に応じて専門家または個人情報保護委員会の相談窓口で確認する【要確認】。

【運営者名】（以下「運営者」）は、【サービス名】（以下「本サービス」）でお預かりする個人情報を、次のとおり取り扱います。

## 1. 運営者
- 名称：【運営者名】
- 連絡先：【問い合わせ先（メールアドレス等）】
- 住所：【住所。請求があれば遅滞なく開示する方式の場合はその旨】

## 2. 取得する情報
| サービス | 取得する情報 |
|---|---|
| 共通 | 購入時に販売プラットフォームを通じて得る情報（購入者名・連絡先など、プラットフォームが提供する範囲）、申込フォームの回答、問い合わせの内容 |
| ① 経営者向け | 業種・規模、業務の内容と時間、使っているツール |
| ② 家計 | 世帯構成・年代、収入・支出・貯蓄・積立のおおよその範囲、目標 |
| ③ 目標達成 | 目標、現在の状況、使える時間・予算 |
| ④ 受験 | 受験の種類・学年、志望のレベル、模試・テストの結果の目安、学習時間（保護者が入力。受験生の本名・学校名は取得しない） |

口座番号・カード番号・ID・パスワード・マイナンバー、第三者の個人情報、病名など健康に関する詳しい情報は取得しません。

## 3. 利用目的
1. 申込内容にもとづく計画・資料の作成と納品
2. 納品後の修正・見直し（④）・問い合わせへの対応
3. 返金・決済に関する対応
4. 個人を特定しない形での集計（受付件数・作業時間・満足度など）によるサービスの改善

## 4. AIサービスでの処理（外部の事業者への委託・国外での処理）
- 計画・資料の作成のため、申込内容から**氏名・連絡先を除いた必要な項目だけ**を、次のAIサービスに入力して処理します。
  - 【AIサービス名】（提供事業者：【事業者名】、所在国：【国名】）
- AIサービスは、入力内容を学習に使わない設定で利用します【設定を確認した日付】。
- 氏名を除いても、内容の組み合わせによって個人が特定できる場合があります。そのため、入力していただく情報は必要最小限にしています。
- 外国にある事業者が処理する場合の制度・措置について、個人情報保護法にもとづき必要な情報提供と同意の取得を行います【公開前に、委託・提供の区分と必要な説明事項を確認する（要確認）】。
- AIサービス側での保存期間・取り扱いは、その事業者の規約に従います。運営者はAIサービス側のデータの削除を保証できません。

## 5. 保存と削除
| 対象 | 保存期間 | 削除 |
|---|---|---|
| 申込内容・作成用の作業ファイル（①③） | 納品後90日 | 期限後に削除し、削除日を記録 |
| 申込内容・作成用の作業ファイル（②④） | 納品後30日（④は模試後の見直しを申し込んだ場合、見直しの再納品後30日） | 同上 |
| 決済・返金などの取引記録 | 法令で保存が必要な期間 | 期間後に削除 |
| 個人を特定しない集計（件数・作業時間など） | 期限なし | — |

期限前の削除は【問い合わせ先】にご連絡ください。7日以内に対応します（法令で保存が必要な取引記録を除く）。

## 6. 第三者への提供
法令にもとづく場合と、上記4のAIサービスでの処理を除き、本人の同意なく第三者に提供しません。

## 7. 安全管理
- 申込内容は運営者だけがアクセスできる場所に保存し、②④は他のサービスと別の場所に分けて保存します。
- 申込内容を公開の場所（公開リポジトリ・SNS など）に置きません。

## 8. 開示・訂正・削除などのご請求
【問い合わせ先】にご連絡ください。ご本人（④は保護者）であることを確認したうえで対応します。

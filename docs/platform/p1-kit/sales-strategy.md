# 販売方針（P1・最初の12件）

ChatGPT と合意した方針（2026-10-30）。公開・販売開始・有料契約はオーナーの承認後。

## 1. 決定事項
| 項目 | 決定 |
|---|---|
| 販売場所 | **ココナラに4サービスとも出品**。最初は「売り場」ではなく**需要を確かめる場所**と位置づける（類似サービスも販売数は数件〜十数件。出品しただけで売れる前提にしない） |
| 売上の主軸 | **①AI業務改善（経営者・個人事業主向け）**。最も高単価で、法人契約・継続改善に広げやすい。Instagram の発信量・改善の手間は①を優先する |
| ②③④ | 同時に出品して需要を検証する。安売りは続けない |
| 価格 | 最初の3件だけ「モニター価格」。条件を満たしたら通常価格へ（下表） |
| 月額プラン | **最初の12件の検証が終わるまで販売しない**。継続の需要・対応の手間・利益率を見て商品ごとに判断。④は未成年・保護者対応と学習指導との境界の確認が済むまで単発のみ |
| 信頼の作り方 | 資格・実績を装わない。**納品物の具体性と作り方の透明性**で信頼を作る（`coconala-listings.md`）。実際の購入者の評価は本人の同意を得て掲載し、架空の口コミ・成果は作らない |
| note | 無料記事による集客のみ（販売しない） |
| 自社販売（BASE 等・LINE公式） | 12件の検証後に検討。ココナラで出会った顧客を外へ誘導しない（規約順守） |

## 2. 価格
| 商品 | モニター価格（先着3件） | 通常価格 | 通常価格に戻す条件（3件すべて納品後） |
|---|---|---|---|
| ① AI業務改善 | 9,800円 | 19,800円 | 平均評価4.5以上、1件の実作業が見積もり（2時間）の1.5倍以内、返金0件 |
| ② 家計診断＋将来シミュレーション | 1,980円 | 2,980円 | 同上（見積もり30分） |
| ③ 目標達成ロードマップ | 1,980円 | 2,980円 | 同上（見積もり20分） |
| ④ 受験ロードマップ | 3,980円 | 4,980円 | 同上（見積もり30分） |

- 条件を満たさない場合は、値下げを続けるのではなく、内容・説明・対象を見直す。
- 表示は「モニター価格（先着3名）」とし、販売実績のない通常価格を取り消し線で並べない（実際に販売していない価格との比較表示をしない）。
- 手取り（ココナラ手数料22%差引）：モニター価格で①7,644円／②1,545円／③1,545円／④3,105円（AI利用の原価は含まない）。

## 3. Instagram からの導線
```
Instagram 投稿（曜日別シリーズ）
  → 最後のページ「詳しくはプロフィールのリンクから」
  → プロフィールのリンク（4つ。①を一番上）
  → ココナラの各出品ページ
  → 購入 → トークルームでヒアリング → 納品
```
- 発信の比率：①を週2本（月曜＋もう1本）、②③④を各週1本から始め、反応を見て調整する。
- リンクは商品ごとに分け、どのシリーズから何人来たかをインサイトで確認する。

## 4. 最初の12件の検証 KPI（毎週記録・個人情報なし）
| 区分 | 指標 | 取り方 |
|---|---|---|
| 集客 | 投稿の閲覧数、プロフィールへのアクセス、リンクのタップ（シリーズ別） | Instagram のインサイト |
| 出品ページ | 閲覧数、お気に入り数、購入数、購入率 | ココナラの出品者向け管理画面 |
| 納品 | 1件の作業時間（納品／問い合わせ・修正／返金対応に分ける）、納期の順守 | `ledger-template.csv` |
| 満足 | 評価、修正依頼の有無、返金、「また頼みたいか」「継続して見てほしいか」（納品時に一問だけ聞く） | トークルーム・評価 |
| 判定 | 出品ページの対象顧客の閲覧100未満なら需要は判断しない（仕様書4章） | — |

検証の目的は売上だけでなく、**どの作業を標準化・自動化すれば利益が残るか**を測ること。12件の後に、月額化・自社販売・自動化（P3）の順序を決める。

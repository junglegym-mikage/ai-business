# 継続型サービス：初回セットアップ＋現在地ボード＋月次更新

オーナーの事業イメージ（2026-10-30）：「どの事業も、オーナー自身の資産計画のように常に更新でき、現在地と目標が可視化されている」。単発のPDF販売ではなく、**目標を設定する → 現在地を可視化する → 毎月更新する → 計画を直す** という仕組みを売る。

## 1. 商品の構成
| 商品 | 初回セットアップ（モニター価格） | 月次更新プラン（ココナラ「継続購入プラン」） |
|---|---|---|
| ① AI業務改善 | 9,800円：計画書PDF＋現在地ボード | **月4,980円**：事務作業時間・AI化の進み具合を更新 |
| ② AI家計整理・積立シミュレーション | 1,980円：同上 | **月980円**：家計・積立の仮定試算を更新 |
| ③ 目標達成ロードマップ | 1,980円：同上 | **月980円**：現在地・マイルストーンを更新 |
| ④ 受験ロードマップ | 3,980円：同上（模試後の見直し1回込み） | **保留**：法的確認（特定継続的役務との関係）が済むまで販売しない |

- 月次更新は初回を購入した人だけが申し込める。1か月単位で、いつでも解約できる。
- ココナラの継続購入プランの手数料・対象カテゴリは出品前に確認する【要確認】。
- 月額の手取り（22%差引の場合）：①3,885円／②765円／③765円。

## 2. 現在地ボード（`boards/`）
お客さん自身の Google アカウントに Google スプレッドシートとしてコピーして使う（Excel 形式で渡し、Google ドライブで開いてもらう）。

| ボード | お客さんが入れる項目（必要最小限） | 自動で表示されるもの |
|---|---|---|
| ①`board-01-business.xlsx` | 月ごとの事務作業時間、AI化した業務の数 | 目標と実績のグラフ、削減時間、目標までの達成率 |
| ②`board-02-money.xlsx` | 月の貯蓄額、月末の積立残高（おおよそ） | 計画（仮定の利回り）と実績のグラフ、計画との差、貯蓄目標の達成月数 |
| ③`board-03-goal.xlsx` | 段階ごとの状態、週の予定・実績時間 | 今いる段階、進み具合、週の達成率、計画を見直す目安 |
| ④`board-04-exam.xlsx` | 模試の教科別偏差値（または点数）、1週間の学習時間 | 教科別の差と優先度、5教科平均の推移 |

- 入力欄は黄色・青字。記入例は架空。氏名・住所・口座番号・ID・パスワード・学校名を書く欄は作らない。
- **お客さんが更新する項目**：実績（時間・金額・偏差値・段階の状態）。**運営者が更新する項目**：目標・計画（初回の計画書から転記、月次更新で見直した値）。

## 3. 月次更新の範囲（これ以外は含まない）
1. 月1回、お客さんから実績を受け取る（ボードの数字をトークルームに書いてもらう。ボードの共有は求めない）
2. 現在地ボードの目標・計画の値を更新する（更新後の値をトークルームで伝え、お客さんが自分のボードに反映。または更新版のファイルを渡す）
3. 目標との差を確認する
4. 必要な計画変更を行う
5. 1ページの月次レポートを納品する

**含まないもの**：無制限の質問、随時の相談、追加の計画作成、個別指導・授業・添削、ツールの設定代行、ボードの共有による直接編集。②は家計整理と仮定試算の更新に限り、個別の投資判断の助言はしない。

## 4. 個人情報とボードの管理
| 項目 | 方針 |
|---|---|
| ボードの保存場所 | お客さん自身の Google アカウント。運営者はアクセス権を持たない（共有を求めない） |
| 運営者側に残るもの | トークルームで受け取った実績の数字と、作業ファイル（AIに渡す前に氏名・連絡先を除く） |
| 運営者側の削除 | 月次更新の作業ファイルは、その月の納品後30日で削除。解約時は最後の納品後30日で削除し、削除日を記録 |
| お客さん側 | ボードはお客さんの持ち物。解約後も自由に使える。不要になったら自分で削除してもらう（手順を使い方シートに記載） |
| 誤共有の防止 | 運営者からボードの共有リンクを求めない・受け取らない。誤って共有された場合はアクセスせず、共有解除を依頼する |

## 5. 工数・上限・停止条件
- 月次更新の受付は**各商品3名まで**（①②③）。
- 想定の月次作業：①45分、②15分、③15分／人（仮定）。**問い合わせ・決済の確認・解約対応も含めて計測**する（`ledger-template.csv` に月次の行を追加）。
- 1人あたりの実作業が想定の1.5倍を超えたら、その商品の**新規の月次受付を停止**し、価格と範囲を見直す。
- **合計20時間の上限には、初回納品と月次更新の両方を含める。**
- 単月だけでなく累積で見る：3名が12か月続けば最大36回の更新になる。月次更新の総時間を毎月記録する。

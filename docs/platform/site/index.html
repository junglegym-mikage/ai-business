よくある質問

AIにお客様の情報が入りませんか？
AIには、お名前・連絡先・会社名を除いた項目（業種と規模、作業の内容と時間、使っているツールなど）だけを入力します。申込内容にも、顧客・従業員・取引先の個人情報は書かないでください。詳しくは利用規約の「AIの利用」をご覧ください。
AIに詳しくなくても使えますか？
申込内容でAIの利用経験をお聞きし、それに合わせて手順を書きます。指示文はそのまま貼って使える形でお渡しします。
有料のツールを契約する必要はありますか？
前提にしません。申込時に「追加の契約はしない／月◯円までならよい」をお聞きし、その範囲でご提案します。
どれくらい時間が減りますか？
使い方や業務によって変わるため、お約束はできません。資料の中では、申込内容の自己申告にもとづく仮定の試算としてお示しします。
キャンセル・返金はできますか？
申込内容を当方が受領する前なら全額返金します。受領後は作業に着手するため、お客様のご都合による返金はできません。当方の都合で期日までにお届けできない場合は全額返金します。

※結果を保証するものではなく、専門家による個別の助言ではありません。資料はAIで作成し、運営者が確認してからお届けします。

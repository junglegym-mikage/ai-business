# Instagram 開始チェックリスト（アカウント作成の日にやること）

所要：オーナー約20分＋Claude の作業。上から順に。

## オーナーがやること（パスワードや本人確認が必要なため）
1. [x] 運営名とユーザーネーム（2026-10-31 決定：PROCESS PERFORMANCE／@process_performance_ai）（@〜）を決める（候補：`../p1-kit/instagram.md`）。決まるまでは仮の名前で始めてもよい。（候補と商標の簡易確認：`../p1-kit/naming.md`）
2. [x] Instagram で新しいアカウントを作る（ジムや個人のアカウントとは別。顔写真は不要）
3. [ ] 設定 → 「アカウントの種類とツール」→ **プロアカウント（クリエイター または ビジネス）**に切り替え。カテゴリは「教育」または「デジタルクリエイター」など（インサイトと予約投稿・自動返信を使うため）
4. [ ] アプリ内ブラウザ（Claude の画面）で Instagram にログインしておく（以降の入力・予約は Claude が操作。公開・予約の確定はオーナーの「OK」の後）
5. [ ] ココナラの出品が公開されたら、4つの出品ページの URL を Claude に伝える

## Claude がやること（オーナーの「OK」の後に操作）
6. [ ] プロフィールの入力：名前欄・自己紹介（`../p1-kit/instagram.md` の案A〜Cからオーナーが選んだもの）。「AIで作成し運営者が確認しています」を明記
7. [ ] プロフィールのリンクに、ココナラの4出品ページを事業別に登録（①を一番上）※出品前はリンクなしで開始可
8. [ ] 固定投稿3枚（`week1/pinned-1〜3.png`）を投稿してピン留め
9. [ ] 1週目のリール5本（`week1/posts.md`）を予約投稿。ストーリーズは予約できないため、投稿日にオーナーのスマホから2枚上げる（各1分。手順は `week1/posts.md`）
   - ストーリーズの予約は Meta Business Suite で使える場合がある（アンケートなどのスタンプは付けられないことがある）。使えるかを確認して記録
10. [ ] 機能の確認と記録（`../p1-kit/sns-engine.md` の「採用候補」）
   - 試験的なリールが使えるか、予約できるか
   - コメントのキーワード自動返信（Meta Business Suite）が使えるか
11. [ ] 使える場合：キーワード「ボード」の自動DMを設定（下の文面）。DMで送るのは無料サンプルの閲覧リンクとココナラの該当出品ページだけ
12. [ ] 毎週日曜の運用（集計→企画→制作→ChatGPT レビュー→月曜にオーナー承認）を始める

## 自動DMの文面（「ボード」とコメントした人へ）
```
コメントありがとうございます！
記入例入りの「現在地ボード」の見本です（数字はすべて架空です）。
数字を入れると、現在地とゴールまでの道筋が自動で計算されるしくみを見てみてください。
【無料サンプルの閲覧リンク】

ご自分用のボードと計画づくりは、こちらから受け付けています。
①経営のAI化：【ココナラURL】 ②家計・積立：【ココナラURL】
③目標ロードマップ：【ココナラURL】 ④受験ロードマップ：【ココナラURL】
※結果を保証するものではありません。
```
- 無料サンプルは `../p1-kit/boards/` の4ファイルを Google ドライブで「閲覧のみ」で共有する（コピーして使ってもらう形）。個人情報の入力欄はない
- DM でメールアドレス・電話番号・LINE 登録・外部決済には誘導しない

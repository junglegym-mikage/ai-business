# 公開前・送信前QAチェックリスト

自動テスト：`python3 tests/check_pages.py`（標準ライブラリのみ）。下の手動項目と合わせて確認する。

## ページ（自動テストで確認）
- [ ] すべてのHTMLに`lang="ja"`、viewport、`<title>`がある
- [ ] 内部リンク（相対パス）の参照先ファイルが存在する
- [ ] 「購入・決済できない」旨の表示がある（決済の設定前）
- [ ] 「保証します」「必ず」「治る」「No.1」などの禁止表現がない
- [ ] 仮の連絡先（example.com、000-0000など）が残っていない
- [ ] サンプルに「架空」の明示がある

## ページ（手動）
- [ ] スマホ幅（375px）で横スクロールが出ない
- [ ] 価格の横に「仮」「税込」の表示がある
- [ ] 運営者情報・特定商取引法の表記・利用規約・返金条件を、有料の申込み受付前に掲載した
- [ ] 本番（mainブランチ＝GitHub Pages）への反映は、オーナーの承認後に行う

## 送信前（手動）
- [ ] 送信先は、事業者が公表している連絡先である（出典URLをleads.csvに記録）
- [ ] 「営業お断り」の表示がない
- [ ] 送信者名・住所・連絡先・受信拒否方法を記載した
- [ ] 本文の指摘3点は、実際に掲載情報を見て確認した事実である
- [ ] 医療・整骨・整体は対象外
- [ ] 1日の送信数が上限（5件）以内
